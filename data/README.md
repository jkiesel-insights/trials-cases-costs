# Data

Source files are not stored here because of size limits. To reproduce the project, download them and place them in this folder:

- **BYAREA.TXT**: CDC U.S. Cancer Statistics, 1999–2023 data file (https://www.cdc.gov/cancer/dataviz/). Used for 2023 cancer incidence by state.
- **cms_inpatient_geo.csv**: CMS Medicare Inpatient Hospitals by Geography and Service, 2024 (https://data.cms.gov/). Used for chemotherapy costs (DRGs 846–848).

The AACT clinical trials database is restored separately; see "How to Reproduce" in the main README.
